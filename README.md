# 🤖 Code Market

لعبة متجر روبوتات مستوحاة من فكرة الفيديو، تعمل مباشرة داخل المتصفح دون خادم أو تثبيت.

## التشغيل
افتح `index.html` في أي متصفح.

## النشر على GitHub Pages
1. أنشئ مستودع GitHub جديدًا (عامًا).
2. ارفع ملف `index.html` وملف `README.md` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch** ثم **main** و **/(root)** واضغط **Save**.
5. انتظر اكتمال النشر ثم افتح الرابط الذي يظهر في صفحة Pages.

## المميزات
- متجر تفاعلي بمنظور علوي، روبوت قابل للتحريك، زبائن ورفوف ومبيعات.
- ترقيات للسرعة والأرباح والإعلانات والمخزون.
- دعم الجوال والكمبيوتر.
- حفظ تلقائي للتقدم باستخدام localStorage.

> هذه نسخة ويب ثنائية الأبعاد مستوحاة من أسلوب اللعبة في الفيديو، وليست نسخة ثلاثية الأبعاد مطابقة للعبة الأصلية.
